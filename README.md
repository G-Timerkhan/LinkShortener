# LinkShortener

Итоговый проект по Java. Консольное приложение для создания коротких ссылок.

## Возможности:
- Создание коротких ссылок (уникальных для каждого пользователя).
- Ограничение количества переходов.
- Автоматическое удаление ссылок по истечении срока (TTL).
- Проверка прав владельца по UUID.
- Открытие оригинального URL в браузере.
- Настройки в `config.properties`.

## Как запустить:
1. Склонируйте репозиторий.
2. Откройте проект в IntelliJ IDEA.
3. Запустите `org.example.ui.Main`.

## Тестирование:
Запустите `LinkServiceTest` в IDE или выполните `mvn test`.
